Passo a passo: como editar um PDF no celular

  1. 1
    Abra o PDF no modo de edição

    Abra o arquivo no PDF Guru e toque no ícone de lápis (✏️) na barra inferior para entrar no modo de edição completo.

  2. 2
    Adicione ou edite texto

    Toque em "Texto" e clique na página onde deseja posicionar a caixa de texto. Para editar texto existente num PDF com texto selecionável, toque diretamente sobre ele para ativar o cursor de edição.

  3. 3
    Insira imagens ou formas

    Toque em "Imagem" para inserir fotos da galeria ou tirar uma foto diretamente. Use "Formas" para setas, retângulos e linhas de destaque visual.

  4. 4
    Gerencie as páginas

    Toque no ícone de páginas (lista) para abrir o gerenciador. Arraste miniaturas para reordenar, toque em "+" para inserir páginas e em "🗑" para excluir.

  5. 5
    Salve o documento editado

    Toque em "Salvar". O PDF Guru preserva o documento original e salva a versão editada com o sufixo "_editado" para você não perder o original acidentalmente.

PDF escaneado? Use OCR primeiro

Se o seu PDF for uma imagem escaneada (texto não selecionável), use primeiro a ferramenta de OCR do PDF Guru para converter para texto editável. Depois, edite normalmente. Veja o guia: Como extrair texto de PDF com OCR.

Como destacar e anotar texto em PDF

Para destacar trechos importantes sem alterar o conteúdo original:

  1. No modo de edição, toque em "Anotações"
  2. Selecione "Destacar" e escolha a cor (amarelo, azul, verde ou vermelho)
  3. Toque e arraste sobre o texto que deseja destacar
  4. Para adicionar comentário, toque no destaque e selecione "Adicionar nota"

Como reorganizar páginas de um PDF

Precisa colocar o contrato de 10 páginas na ordem correta? Use o gerenciador de páginas:

  1. Com o PDF aberto, toque em "Páginas" (ícone de grade)
  2. Pressione e segure uma miniatura de página para ativá-la
  3. Arraste para a posição desejada entre as outras páginas
  4. Salve ao finalizar a reorganização

Perguntas frequentes

É possível editar o texto original de um PDF pelo celular?

Sim, para PDFs com texto selecionável (não escaneados). O PDF Guru permite editar, adicionar e excluir texto diretamente. Para PDFs escaneados (imagens), use primeiro o OCR para converter em texto editável.

Posso adicionar páginas a um PDF existente pelo celular?

Sim. No gerenciador de páginas do PDF Guru, você pode inserir páginas em branco, páginas de outro PDF ou páginas escaneadas diretamente da câmera em qualquer posição do documento.

Como destacar texto em PDF pelo celular?

No PDF Guru, selecione o texto desejado com o dedo (toque longo + arrastar) e escolha "Destacar" no menu que aparece. Você pode escolher entre azul, amarelo, verde e vermelho.

O PDF editado mantém a formatação original?

Sim. O PDF Guru edita o arquivo mantendo a estrutura, fontes e layout originais. As alterações são incorporadas ao PDF sem recriar o documento do zero.
